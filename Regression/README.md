# 完整解耦回归

本轮包：老河马 build 4、插件实验室 build 3、权限实验室 build 3。先完成桌面检查并通过 TrollStore 手动覆盖安装，再执行本轮真机检查；旧包结果不得计入新包验收。

## 必要覆盖

1. SDK 在仓库外独立消费；原 UI 兼容构建；核心契约、控制器、CLI、服务身份与大输出/超时；全部组件元数据、源代码、签名及资源完整性。
2. 新 App 只读启动与命令行 `--core-status`，确认版本、资源和现有状态。已有环境下 `--core-run` 返回 already_active，未重复调用漏洞。
3. 手机完整重启后，从未激活状态运行一次新核心完整流程，记录内核启动标识、阶段日志、主动用户空间重启、重新进入后的状态与新增崩溃。复用现有 bootstrap，不清空用户环境。
4. 权限实验室：App 身份、root 辅助进程、受控文件创建/读回/删除、经过 ABI 检查的内核头部 4 字节读取。
5. Frida 在独立测试端口 27043 完成自有 App 枚举、附加、模块/符号/内存读取、函数拦截、撤销和卸载。原 27042 服务保持原状。OpenSSH 在 22222 完成固定主机公钥验证、root 登录、SFTP 回环与删除。
6. 五个独立插件分别验证加载、方法、UI、文件、通知。定向加载使用 `PLUGINLAB_MODE=run`；自动注入使用 `automatic`，后者禁止安装和主动 dlopen，必须有全新进程及自动加载证据。
7. 自动注入测试前只读检查现有注入文件；仅在目录中全部为本项目的窄过滤插件时临时开启。保存并恢复 `.safe_mode` 原内容与权限，验证关闭后新进程无自动加载；发现其他插件时停止并评估，不能无差别启用。
8. 将 SSH/Frida 实测结果按 run_id + boot_uuid 回传实验室，核验 accepted。停止本轮自有测试服务，核验进程消失、端口关闭、既有服务不变。功能测试窗口内内核及桌面启动身份保持一致。

## 结果标准

root、内核读取、Frida 附加、定向插件加载、全局自动注入分别记录，不能互相代替。内核测试不包含任意写入；自动注入成功仅说明系统注入路径对自有测试 App 生效，不表示对每个 App 都适用。

完整回归要求新包全部必要项有证据；未安装、设备不可用、未执行或不适用必须明确记录。原始日志、设备信息、SSH 私钥、截图保留在被忽略的本地目录，仓库只保存脱敏结论及测试工具。
